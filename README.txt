МОИ ФИНАНСЫ — персональное приложение

СОДЕРЖИМОЕ
- index.html — приложение
- manifest.webmanifest — параметры установки
- sw.js — офлайн-кэширование
- icon-192.png / icon-512.png — иконки

ВАЖНО
Для установки PWA на iPhone сайт должен быть опубликован по HTTPS. Приложение хранит данные локально в Safari на этом iPhone и не синхронизирует их с сервером. Не очищайте данные сайта без предварительного экспорта резервной копии.

УСТАНОВКА НА IPHONE
1. Разместите все файлы из архива в корне HTTPS-сайта (например, GitHub Pages).
2. Откройте ссылку в Safari на iPhone.
3. Нажмите «Поделиться» → «На экран Домой» → включите «Открывать как веб-приложение» (если такой переключатель доступен) → «Добавить».
4. Запустите приложение с новой иконки. После первой загрузки основные функции доступны офлайн.

НАПОМИНАНИЯ
Приложение показывает напоминание при открытии после выбранного числа, если месяц ещё не заполнен. Полностью офлайн-PWA не может надёжно присылать уведомление по расписанию, пока закрыто. Для гарантированного ежемесячного сигнала настройте повторяющееся событие в приложении «Напоминания» iPhone.

РЕЗЕРВНАЯ КОПИЯ
Вкладка «История» → «Скачать копию» сохраняет JSON со всеми данными. «Восстановить копию» импортирует этот файл.
